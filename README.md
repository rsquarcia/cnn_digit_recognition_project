# cnn_digit_recognition_project
CNN for handwritten digit recognition implementing a custom training loop manually executing backpropagation, achieving 98.2% accuracy on MNIST, there is also a full-stack web application (Flask, HTML/JS) for real-time inference, allowing users to draw digits through a canvas interface.
